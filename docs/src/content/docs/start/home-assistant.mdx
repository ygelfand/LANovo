## Add it

<Steps>

1. **Scan the code** with your phone. It opens Home Assistant's "add ESPHome device" screen.

2. **Enter the address** shown under the code, like `192.168.1.50:6053`.

3. **Submit.** The display and Home Assistant set up encryption automatically; the default
   installation does not require you to enter a password or key.

4. Open the ESPHome integration's options for the display and turn on **Allow the device to perform
   Home Assistant actions**. This is needed for Tessera, home control and picking wake words on
   the screen.

</Steps>

If Home Assistant has already discovered the display, open **Settings → Devices & services** and
add the discovered ESPHome device instead.

## In Home Assistant

The display's entities are grouped into sub-devices:

| Part | Contents |
|---|---|
| **Screen** | Brightness, theme, clock face, screen saver, wallpaper |
| **Microphone** | Gain, leveling, noise suppression, room and stop word sensitivity |
| **Playback** | Now playing, chimes, and volumes for main, media, voice, alerts and system sounds |
| **Camera** | Snapshot camera, RTSP switch, username and password, picture settings |
| **Assistant 1** and **Assistant 2** | Wake word, pipeline, sensitivity and sound |
| **Voice triggers** | Switches for the [voice actions and commands](/features/voice/#voice-triggers) |
| **Dashboard**, **Landscape**, **Portrait** | Tessera, when it's in use |

The main device contains the media player and privacy switch sensors. Additional sensors report
ambient light, presence, temperature, memory and Wi‑Fi signal.

## Encryption key

If you installed with `./lanovo install --generate-key`, Home Assistant asks for a key. Get it with:

```sh
./lanovo key
```
