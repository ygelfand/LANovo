`lanovo` installs LANovo on the display over USB and connects it to your Wi‑Fi.

## Get lanovo

Download `lanovo` for your computer from the
[Releases page](https://github.com/ygelfand/LANovo/releases). It's a single file with LANovo
inside it.

<Tabs>
	<TabItem label="macOS">
		```sh
		cd ~/Downloads
		mv lanovo_darwin_arm64 lanovo
		chmod +x lanovo
		```
		On an Intel Mac, the file is `lanovo_darwin_x86_64`. If macOS says it can't check the file for
		malware, right-click it in Finder, choose **Open**, then run it again from the terminal.
	</TabItem>
	<TabItem label="Linux">
		```sh
		cd ~/Downloads
		mv lanovo_linux_x86_64 lanovo
		chmod +x lanovo
		```
		On ARM, such as a Raspberry Pi, the file is `lanovo_linux_arm64`.
	</TabItem>
	<TabItem label="Windows">
		In PowerShell:
		```powershell
		cd ~\Downloads
		Rename-Item lanovo_windows_x86_64.exe lanovo.exe
		```
		On an ARM PC, the file is `lanovo_windows_arm64.exe`. Use `.\lanovo.exe` wherever this guide
		says `./lanovo`.
	</TabItem>
</Tabs>

## Install

Plug the display in over USB and run:

```sh
./lanovo install
```

What it does, in order:

1. Turns off dm-verity, if it's on, and reboots.
2. Asks for a name for the display.
3. Sets SELinux to permissive on the boot command line, and reboots.
4. Installs lanovod and its service, and reboots.
5. Joins Wi‑Fi: pick a network and type its passphrase, unless you gave `--ssid` and `--password`.
6. Starts lanovod and shows a code to add the display to Home Assistant.

The display reboots up to three times. Leave the cable in until `lanovo` finishes.

Renaming the display later makes Home Assistant see it as a new device, so pick a name you'll keep.

<Aside type="tip" title="More than one display">
`./lanovo install --name "Bedroom Display" --ssid MyWiFi --password 'your-password' --yes --reboot`
</Aside>

## Options

| Option | What it does |
|---|---|
| `--name "Kitchen Display"` | Name the display without being asked |
| `--ssid MyWiFi --password …` | Join this network without scanning |
| `--wps` | Join by pressing your router's WPS button |
| `--yes` | Don't ask before installing |
| `--reboot`, `--no-reboot` | Reboot at the end without asking, or finish without rebooting |
| `--generate-key` | Make the encryption key here, to paste into Home Assistant, instead of letting Home Assistant set it |
| `--serial HUA0XXXXX` | Pick a display when more than one is plugged in |

## Changing Wi‑Fi later

```sh
./lanovo wifi --force
```

`--force` lists the networks even when the display is already connected; without it, a connected
display just reports where it is. Once the new network connects, the display forgets every other
network; if it does not connect, the display goes back to the one it was on.
