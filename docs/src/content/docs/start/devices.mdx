LANovo detects the model itself.

| | Smart Display 10 | Smart Display 8 | Smart Display 7 | JBL Link View | ThinkSmart View |
|---|---|---|---|---|---|
| **Codename** | blueberry | amber | ivy | opal | penghu |
| **Status** | Supported | Supported | Supported | Supported | Supported |
| **Screen** | 10.1", 1920 × 1200 | 8", 1280 × 800 | 7", 1024 × 600 | 8", 1280 × 800 | 8", 1280 × 800 |
| **Rotation** | Automatic | Automatic | Landscape | Landscape | Automatic |
| **Camera** | Yes | Yes | Yes | Yes | Yes |

## Smart Display 10 (blueberry)

The reference device; every feature is developed and tested on it first.

## Smart Display 8 (amber)

Tested and running on hardware. The same Qualcomm platform as the Smart Display 10, with an
8-inch, 1280 × 800 screen and automatic rotation.

## Smart Display 7 (ivy)

MediaTek instead of Qualcomm, with a compact layout. Landscape only.

<Image src={sd7} alt="A Smart Display 7 running LANovo" class="device device-small" />

<Image src={sd7Saver} alt="The Light Cycles visual on a Smart Display 7" class="screen-wide" />

## JBL Link View (opal)

Qualcomm, stereo speakers. Landscape only. Unlock it with the Smart Display 8/10 guide and flash the
**Android 8.1 Debug Firmware** (see [Before you install](/start/before/)).

<Image src={jbl} alt="The Light Cycles visual on a JBL Link View" class="screen-wide" />

## Lenovo ThinkSmart View (penghu)

<Aside type="note">

## Smart Clock

Not supported yet. Different hardware.
