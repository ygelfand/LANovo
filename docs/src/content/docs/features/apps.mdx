description: The Apps screen and dock favorites.
---

The grid in the dock opens the Apps screen. Star an app to keep it in the dock; drag to reorder.

| App | |
|---|---|
| **Intercom** | [Calls](/features/intercom/) to other displays and Echos |
| **Mirror** | Camera, full screen |
| **Media** | The player |
| **Shopping list** | A Home Assistant to-do list |
| **Calendar** | Upcoming events from Home Assistant calendars |
| **Radar** | Animated weather radar with a short-range forecast |

The shopping list and calendars are set under **Settings → Home control**.
