## RTSP

RTSP is off by default. Turn it on under **Settings → Connected services → Camera stream**, or with the
**RTSP server** switch (`rtsp`) in Home Assistant.

```text
rtsp://192.168.1.50:8554/main
rtsp://192.168.1.50:8554/sub
```

`main` is the main camera stream; `sub` is a smaller stream for previews and motion detection. Turn either
off, and set their resolutions, under **Settings → Camera → Streams**.

| Device | Main resolutions | Sub stream widths |
|---|---|---|
| Smart Display 10, Smart Display 8, JBL Link View, ThinkSmart View | 1920×1080, **1600×1200**, 1280×960, 1024×768, 800×600, 640×480 | 960, 768, **640**, 480, 320 px |
| Smart Display 7 | **1280×720**, 864×480, 640×480 | 960, **768**, 640, 480, 320 px |

Defaults in bold. The sub stream keeps the main stream's shape and is never wider than it.

ONVIF discovery is supported.

## Password

Set a password under **Settings → Connected services → Camera stream**, or with **RTSP password**
(`rtsp_password`) in Home Assistant. RTSP, ONVIF and the ONVIF snapshot endpoint then ask for it, with
the username `admin` unless you change it (`rtsp_username`). Leave the password empty to turn it off.

Use the same username and password in your recorder or Home Assistant's ONVIF integration.
For a player that takes credentials in the stream URL:

```text
rtsp://admin:password@192.168.1.50:8554/main
```

## Snapshot

Home Assistant gets a **Camera** entity (`camera`) with JPEG still pictures. It uses the ESPHome
connection and does not require the RTSP server to be on. Add that camera entity to a Home Assistant
dashboard to see the display's camera there.

This ESPHome camera entity does not use the RTSP username or password.

To save a picture from a Home Assistant script or automation, use **Camera: Take snapshot**
(`camera.snapshot`), select this camera entity and supply a filename in a directory Home Assistant
can write to. For example:

```yaml
action: camera.snapshot
target:
  entity_id: camera.kitchen_camera
data:
  filename: /config/www/kitchen-snapshot.jpg
```

Replace the entity ID with your camera's actual ID. Files in `/config/www` are served by Home
Assistant under `/local/`; use a different allowed directory if the picture must not be web-accessible.

With the shutter closed, this entity returns a privacy card instead of a room picture.

## Picture

**Settings → Camera** has a live preview and pages for **Picture**, **Exposure**, **White Balance**
and **Streams**, and **Reset to defaults**. Every setting is listed on
[Settings on the screen](/use/settings/#camera) and is also in Home Assistant. Camera settings
aren't copied by config sync.

## Shutter

With the shutter closed, the stream, calls, the camera preview and Mirror show **Camera shutter is
closed** instead of the picture, and a privacy mark shows on screen. Home
Assistant's **Camera covered** sensor (`camera_covered`) follows it.


<Aside type="caution">
Without a [password](#password), anyone on your network can watch the stream while it's on.
</Aside>
