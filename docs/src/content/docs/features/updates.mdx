---
title: Updates
description: Updating from Home Assistant, the screen or ADB, and installing another version.
---

## From Home Assistant

New versions show up under **Settings → Updates** through the display's **Firmware** entity.
Install from there, or press **Check for updates** to look now. The previous version is kept until the new one is running.


## From the screen

**Settings → System → Software update** shows the current version, **Check for updates**, and
**Download and install** when an update is available.

## Checks

The display checks for updates a few minutes after startup, then daily. **Update status** shows
progress, and **Update outcome** fires when an update finishes or fails.

## Update channel

**Update channel** (`update_channel`), on the screen or in Home Assistant:

- **Stable** (`stable`): releases
- **Development** (`dev`): the latest builds, for trying fixes early

Only newer builds are offered as updates.

## Other versions

To go back to an earlier version, or try a particular one, open **Settings → System → Software
update → Other versions**. It lists the published releases, each marked Stable or Development, with
the running one marked **Installed**. Tap one and confirm; it installs and LANovo restarts.

In Home Assistant, pick the version in **Install version** (`select.<device>_install_version`) and
press **Install selected version** (`button.<device>_install_selected_version`). Picking alone
installs nothing.

## From ADB

With ADB connected, list releases for the display or install a particular release tag:

```sh
adb -s <serial> shell lanovod ctl firmware list
adb -s <serial> shell lanovod ctl firmware install <version>
```

Use the exact version tag. Older releases can be installed without changing the update channel.
Installing restarts the display; the control connection may close during restart. Check the
running version after it returns:

```sh
adb -s <serial> shell lanovod ctl device version
```

These commands need a running lanovod and network access to download the release. They do not
need the screen or Home Assistant. If the daemon cannot start, reinstall through the host CLI.
