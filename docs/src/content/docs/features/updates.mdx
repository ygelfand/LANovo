---
title: Updates
description: Updating from Home Assistant or from the display.
---

## From Home Assistant

New versions show up under **Settings → Updates** through the display's **Firmware** entity. The
previous version is kept until the new one is running.

## From the display

**Settings → System → Software update** shows the current version, **Check for updates**, and
**Download and install** when an update is available.

## Checks

A few minutes after start, then daily.

## Update channel

- **Stable**: releases
- **Development**: latest builds

Only newer builds are offered.
