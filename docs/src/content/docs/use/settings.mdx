The gear in the dock opens **Settings**. Every setting here is also an entity on the display in
Home Assistant unless the table says otherwise, and a change in either place shows up in the other.
Settings that only exist in Home Assistant are on [Settings in Home Assistant](/use/entities/).


The **Entity** column is the entity id Home Assistant gives it by default, with `<device>` standing for
your display's name. "—" means the setting is only on the screen.

## Network & internet

The Wi‑Fi network, IP and MAC address, router and DHCP lease, all read-only. Change networks with
[`./lanovo wifi`](/start/install/#changing-wifi-later). When the router offers a different address
from the one the display had before, the display takes the new one.

| Setting | What it does | Default | Entity |
|---|---|---|---|
| Web access → | The address of the [web page](/use/web/), the admin password, and the certificate in use | | `text.<device>_frontend_admin_password`, `sensor.<device>_frontend_certificate` |
| Verify certificates | Check TLS certificates on downloads: updates, wake words, photos, radar | On | `switch.<device>_verify_certificates` |

### Settings Lock

**Set PIN** asks for 4 to 8 digits, twice. From then on the gear asks for the PIN before Settings
opens; **Change PIN** and **Remove PIN** are on the same page. After five wrong PINs it makes you
wait 30 seconds, doubling with each wrong PIN after that, up to an hour.

The lock covers the screen only. If you forget the PIN, clear **Settings Lock** in Home Assistant.
