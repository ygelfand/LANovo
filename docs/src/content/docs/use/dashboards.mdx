The dashboard is the display's home screen. Choose its **Mode** in
**Settings → Dashboard**:

- **Native**: a big clock, the weather, and tabs for your lights, switches, cameras, doorbells and
  alarm panel
- **Tessera native**: pages of tiles you lay out in Tessera in Home Assistant, drawn by LANovo
  in your style and theme
- **Tessera embedded**: the same Tessera pages, drawn by Tessera's own screen software running on
  the display

**Mode** shows when home control is on and Home Assistant actions are allowed; otherwise the
dashboard is native. The button beside it reloads the dashboard from Home Assistant.

## Native

[wallpaper](/features/photos/) behind it. Pick the clock face, position, size and color under
**Settings → Dashboard → Clock**. There are 21 faces: Plain, Stack, Cards, Flip, Analog, Analog
seconds, Roman, Railway, Octagon, Atomic, Spoken, Math, Smiley, Neon, Bars, Reel, Binary, Segments,
Nixie, Words and Overlap.

### Lights and switches

Open **Settings → Dashboard → Lights** (or **Switches**) and turn on **Enable**; the
dashboard gains a **Lights** (or **Switches**) tab. **Select devices** picks what goes on it by
label, by area or one by one, and **Group by area** sets how it's grouped:

- Every device on its own card
- Areas with a few devices on one card
- Every area on one card

<Image src={lights} alt="The Lights tab, with a card per room" class="screen" />

The same cards open full screen from the **Lights** and **Switches** apps on the Apps screen.

### Cameras

Turn on **Settings → Home control → Cameras → Dashboard tab** and the dashboard gains a **Cameras**
tab with the pictures from the [Cameras app](/features/apps/#cameras). Tap a camera to watch it full
screen.

### Doorbell and Home alarm

**Settings → Home control → Doorbell → Dashboard tab** adds a **Doorbell** tab once a
[doorbell](/features/doorbell/) is set up. **Settings → Home control → Home alarm → Dashboard tab**
adds a **Home alarm** tab once an [alarm panel](/features/home-alarm/) is picked.

### Weather

Pick a Home Assistant weather entity under **Settings → Home control → Weather**, then choose how it
looks on the dashboard and on the screen saver: Compact, Stack, Card, Detail, Icon or Words, with
or without animation, in the weather's colors or the theme's, and where it sits. The dashboard and
the screen saver each have their own layout.

Every weather setting is on [Settings on the screen](/use/settings/#weather).

#### Severe-weather alerts

Turn on **Settings → Dashboard → Weather → Weather alerts** (`weather_alerts` in Home Assistant).
It is off by default. The display checks the National Weather Service for **Severe** and
**Extreme** alerts covering the location of Home Assistant's **Home** zone (`zone.home`), not the
weather entity's location. This is a US service and requires internet access.

Allow **the device to perform Home Assistant actions** in its ESPHome integration options; this
lets it request the Home zone's coordinates. Set the Home zone's location correctly in Home
Assistant before enabling alerts.

A warning replaces the weather card with its event name, hazard picture and end time. Tap the card
to open Radar focused on the warning, or **Dismiss** to hide it. Dismissal is saved across restarts
and also hides updates that refer to that warning. If several warnings are active, the most severe
undismissed one appears first.

Alerts use the native dashboard's weather card, not Tessera tiles: keep **Show on dashboard** on
and open the clock tab to see them there. For the screen saver,
turn on **Settings → Display → Screen saver → Weather → Show on screen saver**. They are not a
full-screen alarm or a spoken announcement. Checks run every five minutes; use official emergency
alerts for time-critical warnings.

### Presence and room sensors

Turn on **Settings → Display → Screen saver → Wake on motion** to wake the display when someone
approaches. Presence also keeps the screen awake while the sensor continues to detect someone.
This is off by default. **Detection range** runs from **1** (least sensitive) to **5** (most
sensitive), with **3** as the default; these are sensitivity levels, not distances in metres.

Home Assistant gets **Presence** (`presence`), **Proximity** (`proximity`), **Ambient light**
(`ambient_light`) and **Orientation** (`orientation`). Presence uses the proximity sensor, not the
camera or a microphone. It reports nearby occupancy after a rise over the background reading,
and clears after the reading stays low for ten seconds. Use it for an approach-triggered
automation, not as a guarantee that the whole room is empty.

For example, trigger a Home Assistant automation when the display's **Presence** entity turns
on, then turn on a nearby light. Select the actual device entity in the automation editor;
**Wake on motion** only controls the screen and does not disable the Presence entity.

**Ambient light** reports lux and feeds [automatic brightness](/use/settings/#display).
**Proximity** is a raw sensor reading, not a distance measurement. Automatic orientation follows
the accelerometer on displays that support rotation.

## Tessera

[Tessera](https://github.com/MaxGramser/homeassistant_espscreen) is a Home Assistant integration
with a drag-and-drop editor for touch screens. The display shows up in Tessera like any other
screen; lay out the pages there. There are two ways to show them:

- **Tessera native**: LANovo speaks Tessera's screen protocol and draws the tiles in your style
  and theme.
- **Tessera embedded**: the display runs Tessera's own screen software, so pages look and behave
  as they do on Tessera's screens. Its own settings appear as entities on the display's Tessera
  sub-devices in Home Assistant.

Both use the same Tessera screens, so a layout works in either mode.

### Set it up

<Steps>

1. Install Tessera in Home Assistant from its
   [GitHub page](https://github.com/MaxGramser/homeassistant_espscreen).

2. On the display, set **Settings → Dashboard → Mode** to **Tessera native** or **Tessera
   embedded**.

3. The display appears in Tessera as a screen. Without tiles it shows:

   <Image src={setup} alt="A screen asking to be set up in Tessera" class="screen-wide" />

4. Add pages and tiles in Tessera's editor. They show up on the display.

</Steps>

The Smart Display 10, Smart Display 8 and ThinkSmart View appear as two screens, one for landscape
and one for portrait, so you can lay each out for the way the display is standing. The others
appear as one.

In a Tessera mode, **Settings → Dashboard** has:

| Setting | What it does |
|---|---|
| Screen saver | **Native**, or Tessera's screen saver |
| Grid | Tiles along the long side and the short side |
| Go back to the home page after the screensaver | Return to the first page when the display wakes |
| Enable landscape, Enable portrait | Which orientations to offer (Tessera native, on displays that rotate) |
| Swipe up from the bottom | Tessera embedded: what a swipe up from the bottom edge opens: **Page panel** (the default), **Home page** or **Nothing** |
| Use this device's theme | Tessera embedded: draw in the display's theme colors (on by default) |
| Page transition | Tessera embedded: None, Slide, Cover, Reveal, Deck, Zoom or Fade (Slide by default) |
| Page follows finger | Tessera embedded: the page moves with your finger while you swipe (on by default) |

With Tessera embedded, also turn on **Auto standby** in Tessera's own screen settings to use its
screen saver.

Tile controls require **Allow the device to perform Home Assistant actions** in the display's
ESPHome integration options. Check this permission if tiles appear but do not respond to taps.

## Rotation

The Smart Display 10, Smart Display 8 and ThinkSmart View rotate automatically. The
dashboards, settings, camera and everything else turn with them.
