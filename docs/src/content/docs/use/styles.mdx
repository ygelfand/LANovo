**Style** sets shapes, borders, shadows and type. **Theme** sets colors. Both apply to everything on
the display and are under **Settings → Display** and in Home Assistant.

<img src="/anim/tessera-styles.webp" alt="One page in all nine styles" class="screen" width="540" height="864" />

## Styles

| Style | Look |
|---|---|
| **Standard** | Flat cards |
| **Material You** | Rounded tiles |
| **Glass** | See-through panels |
| **E-ink** | Paper and ink |
| **Metro** | Flat squares |
| **Terminal** | Monospace, green screen |
| **Hi-fi** | Backlit receiver display |
| **Neon** | Glowing outlines |
| **Skeuo** | Raised buttons |

## Themes

**Default** uses the style's palette.

- **Dark:** Midnight, Nocturne, Slate, Ember, Forest, Ocean, Plum, Carbon, Phosphor, Amber, Graphite,
  Synthwave
- **Light:** Paper, Linen, Mist, Bloom, Braun, Ink
