**Style** sets shapes, borders, shadows and type. **Theme** sets colors. Both apply to everything on
the display and are under **Settings → Display** and in Home Assistant.

## Styles

|---|---|
| **Standard** | Flat cards |
| **Material You** | Rounded tiles |
| **Glass** | See-through panels |
| **E-ink** | Paper and ink |

| **Terminal** | Monospace, green screen |
| **Hi-fi** | Backlit receiver display |
| **Neon** | Glowing outlines |
| **Skeuo** | Raised buttons |

## Themes

**Default** uses the style's palette.

- **Dark:** Midnight, Nocturne, Slate, Ember, Forest, Ocean, Plum, Carbon, Phosphor, Amber, Graphite,
  Synthwave
- **Light:** Paper, Linen, Mist, Bloom, Braun, Ink

## Custom theme

The **Custom** tile is the last in the theme picker. Tap it to use your colors; tap its pencil to
edit them. The editor has six colors: Background, Cards, Text, Secondary text, Accent and Second
accent. Select a color, then adjust it with the square and hue slider. Changes save automatically
after release and apply to the screen. Unchanged colors use Paper's palette.

Custom counts as a dark theme when its background is dark.

In Home Assistant the six colors are text entities that take `#rrggbb`; an empty value goes back to
Paper's color.
