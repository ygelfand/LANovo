## Choose a visual

Pick a visual in **Settings → Display → Screen saver → Visual 1** and its source in
**Visual 1 audio**. Add a second in **Visual 2** to split the screen. These are also in Home
Assistant.

See [The screen saver](/use/screen-saver/) for the other options.

## Assistants

Each voice assistant can show a visual while listening, waiting and responding, in the panel or
full screen. Set them under **Settings → Voice assistants → Assistant 1** (or **2**) **→ Visuals**
([Voice assistants](/features/voice/)).
