Most settings can be changed in three places. A change in one shows up in the others.

## On the display

The gear in the dock opens **Settings**. See [Settings](/use/settings/) for what's where.

## From Home Assistant

The same settings are entities on the display's device: switches, selects and numbers for the
screen, screen saver, sounds, voice assistants, camera and the rest. Use them from the device page,
dashboards or automations.

## Config sync

Copy settings between LANovo displays on the same network.

<Steps>

1. On one display, open **Settings → System → Config sync**.

2. Pick another display, then **send** this display's settings to it, or **fetch** its settings.

3. Enter the six-digit code shown on the other display.

</Steps>
