---
title: All settings and defaults
description: Every setting, with its default, its choices and its Home Assistant entity, generated from the code.
---

Every setting on the display, grouped by feature, with the value it starts at and what it can be
set to. The **Entity** column is the entity id Home Assistant gives it by default, with `<device>`
standing for your display's name. A model in brackets means the setting exists only there.

For what each setting does, see [Settings on the screen](/use/settings/) and
[Settings in Home Assistant](/use/entities/).
